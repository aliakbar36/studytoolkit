Time Calculator

Add or subtract hours and minutes from a starting time.

Time Calculator

Enter a starting time and a valid number of hours and minutes.
—

What This Tool Does

This tool adds or subtracts a number of hours and minutes from a starting time — useful for working out when a study block will end, or what time you started if you know how long you worked and when you finished.

Handling Midnight

If adding time pushes past midnight, or subtracting time goes before midnight, the result correctly wraps to the next or previous day's clock time, and the result notes that a day boundary was crossed.

Worked Example

Starting at 10:30 PM, adding 3 hours 45 minutes:

10:30 PM + 3h 45m = 2:15 AM (next day)

How to Use This Tool

  1. Enter your starting time.
  2. Choose whether to add or subtract time.
  3. Enter the number of hours and minutes to add or subtract.
  4. Click "Calculate" to see the resulting time.

Limitations and Common Mistakes

  • This tool works with a single starting time and offset — it doesn't track specific calendar dates, only clock time.
  • Hours and minutes must be zero or positive; to subtract, use the "Subtract time" option rather than entering a negative number.
  • Results that cross midnight are labeled "next day" or "previous day" so you don't lose track of the date change.

Frequently Asked Questions

Can I add more than 24 hours?

Yes — the tool will wrap correctly across multiple days, though the result only displays the resulting clock time and whether it crossed into a different day, not a specific date.

What if I need to subtract a time and go before midnight?

The tool wraps to the previous day's clock time automatically and notes that in the result.

Does this tool account for AM/PM?

Yes — the time input and result both use your browser's standard time format, which typically follows your device's regional settings.
